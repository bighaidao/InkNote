## 2. 详细功能规约

### 2.1 VS Code / PyCharm 风格经典专业文件图标体系
- **设计基调**：告别粗糙通配单色与卡通感，全面对齐 VS Code / JetBrains 经典设计语言：
  - **文件夹 (Folder)**：VS Code 标志性金黄色扁平折角文件夹（关闭态折角收拢，展开态向下开口）；
  - **代码与脚本**：
    - `Python (.py, .pyw)`：经典双色交错蓝黄 Python 双蛇标；
    - `TypeScript (.ts, .tsx)`：深蓝底色 + 白色几何 `TS` 徽标；
    - `JavaScript (.js, .jsx, .mjs)`：经典亮黄底色 + 黑色几何 `JS` 徽标；
    - `Rust (.rs)`：经典铁锈橙机械齿轮标；
    - `HTML (.html, .htm)`：经典 HTML5 橙红科技盾牌；
    - `CSS/SCSS/LESS (.css, .scss)`：经典 CSS3 宝蓝盾牌与井号标；
    - `Markdown (.md, .markdown)`：国际通用方框 `[M↓]` 经典纯黑/白标；
    - `JSON / YAML / TOML`：经典琥珀金花括号 `{ }` 与配置标；
    - `Shell (.sh, .bash, .zsh)`：终端命令行绿色提示符标；
    - `Git (.gitignore, .gitattributes)`：经典 Git 橙红分支分叉标；
  - **Office 与专用文档系列**：
    - `Word (.docx, .doc, .rtf)`：经典微软深蓝底白色粗体 `W` 标；
    - `Excel (.xlsx, .xls, .csv)`：经典微软翠绿底白色粗体 `X` 标；
    - `PowerPoint (.pptx, .ppt)`：经典微软橙红底白色粗体 `P` 标；
    - `PDF (.pdf)`：经典 Adobe 亮红几何标；
    - `压缩包 (.zip, .rar, .7z, .tar, .gz)`：金黄色拉链公文包；
    - `图片 (.png, .jpg, .svg, .webp)`：经典渐变相框插画标；
- **渲染实现**：全部以精细 16x16 矢量 SVG 内联字典驱动（`vscode-icons.json`），纯静态无第三方大型依赖，体积 <25KB，首屏秒开。

### 2.2 Word / PPT / Excel / PDF 全格式文本复制与提取（核心强需求）

#### 1) 鼠标选区划选复制 (Selection Copy)
- 在任何预览界面（包括 PDF 页面、Word 排版区、Excel 单元格表格、PPT 幻灯片、代码行）：
  - 用户用鼠标拖拽划选任意一段文本；
  - 右键任意位置，菜单第一项高亮激活：`📋 复制选中文本   Cmd+C`；
  - 支持快捷键 `Cmd+C` / `Ctrl+C` 直接拷入系统剪贴板。

#### 2) 全文文本智能提取 (Extract Full Text)
- 用户预览 PDF、Word、PPT、Excel 时，往往需要摘录整篇文档或讲义，直接提供双重入口：
  - **入口 A（右键菜单）**：`📄 复制全文文本 (Copy All Text)`；
  - **入口 B（顶部工具栏）**：常驻高辨识度按钮 `[ 📋 提取并复制全文 ]`；
- **各格式提取引擎**：
  - **PDF**：遍历当前 PDF 文档（通过 `pdfjs.getTextContent()`），自动按自然段合并换行；
  - **Word (docx)**：从已解析 DOM 的段落节点或 `document.xml` 中提取全部段落与表格纯文本；
  - **Excel (xlsx)**：将活动工作表内容转换为规范的 TSV/表格纯文本（支持无缝粘贴回 Excel/Numbers/Markdown 表格）；
  - **PPT (pptx)**：提取幻灯片内所有 Shape/Text 节点的文本内容，按页码顺序输出；
- **用户感知与反馈**：
  - 提取完成写入剪贴板后，弹出系统 Toast 反馈：`“已复制 1,850 字到剪贴板”`；
  - 若文档纯为扫描图（无文字层），给予友好提示：`“该文档为纯图像扫描件，未包含可选文本”`。

### 2.3 代码预览增强与 HTML 渲染双模式

- **代码预览工具栏**：
  - 语言与规格：左侧展示语言经典图标（Python/TS/Rust等） + 文件大小 + 行数统计；
  - 操作区：右侧常驻【一键复制代码】（点击即变绿勾）、【查找 (Cmd+F)】快捷提示；
  - 主题自适应：跟随 InkNote 亮色/深色主题，采用开发级语法高亮配色，彻底解决发灰无对比度问题；
- **HTML 双模式预览**：
  - **网页渲染视图 (Rendered Web View)**：默认模式，安全受限沙箱 `<iframe sandbox="allow-same-origin allow-scripts">`，呈现真实页面排版；外链与跳窗重定向至桌面系统默认浏览器；
  - **源码高亮视图 (Source Code View)**：通过顶部 `[ 👁 网页渲染 | 💻 源代码 ]` 分段控制器无缝切换回 CM6 代码高亮编辑器。

## 4. 四种极限交互态定义

1. **空数据态 (Empty State)**：
   - 预览 0 字节文本或纯空文档时，居中展示微淡图标 + 状态文案：“文档内容为空”，提供【复制文件路径】与【在访达中显示】；
2. **加载等待态 (Loading State)**：
   - 解析巨型 PDF/Word 时，展示微淡骨架屏 + 文件经典徽标平滑呼吸动效，操作按钮置灰防重复触发；
3. **文本提取中态 (Extracting State)**：
   - 点击【复制全文文本】抽取大型 PDF 时，按钮变为旋转 Loading，提取完成瞬间变为绿勾 `✓ 已复制 (1,420字)` 并弹出轻量 Toast；
4. **极端数据态 (Extreme State)**：
   - 扫描件 PDF（全为位图、无 textLayer）：提取时捕获并友好提示：“该 PDF 属于纯扫描图片，未包含文本层”，并引导“用系统默认应用打开”。
